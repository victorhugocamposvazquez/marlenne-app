# Marlén · Web corporativa

Marketing, planes, legal y enlace «Entrar» hacia `marlen-app`. Proyecto Next.js
independiente del monorepo Marlén.

## Arrancar

```bash
cd main-website
npm install
cp .env.example .env.local
npm run dev
```

Abre [http://localhost:3002](http://localhost:3002).

## Deploy

Proyecto Vercel con Root Directory `main-website`. Dominio sugerido: `marlen.app`.
